# Sistema de Gestión de Tareas - Backend API

API RESTful desarrollada con Node.js, Express, TypeScript y MongoDB para la prueba técnica de Instaleap[cite: 1].

##  Arquitectura
* `src/api`: Rutas de Express[cite: 1].
* `src/controllers`: Controladores HTTP[cite: 1].
* `src/services`: Lógica de negocio[cite: 1].
* `src/persistence`: Modelos de base de datos y conexión[cite: 1].
* `src/config`: Configuración Singleton[cite: 1, 2].
